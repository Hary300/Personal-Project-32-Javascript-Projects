# 06 — Modules

Pisahkan logic.

Contoh:

```
06-modules/


expenseTracker.js
index.js
```

`expenseTracker.js` berisi:

```js
createExpenseTracker;
```

`index.js` digunakan untuk menjalankan dan mengetesnya.

Gunakan:

```
export
import
```

Tujuan level ini:

Memahami bagaimana function/data dapat digunakan antar-file tanpa menggunakan global variable.
