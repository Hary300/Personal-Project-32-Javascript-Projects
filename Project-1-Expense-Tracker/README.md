# 💰 Project — Expense Tracker

## 🎯 Tujuan

Membuat aplikasi pengelola keuangan sederhana menggunakan Vanilla JavaScript.

Project ini digunakan untuk melatih:

- Function
- Parameter & argument
- Return value
- Scope
- Lexical scope
- Closure
- Object
- Array
- Reference
- Array methods
- Module
- DOM manipulation
- Event handling
