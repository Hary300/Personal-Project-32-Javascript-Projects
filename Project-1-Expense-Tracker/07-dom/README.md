```
--------------------------------

--------------------------------

--------------------------------

[ Makan             ]

--------------------------------


Transactions


Gaji          + Rp 5.000.000
Makan         - Rp 50.000

```

## Fitur

User bisa:

- Tambah transaksi
- Melihat transaksi
- Melihat balance
- Melihat total income
- Melihat total expense
- Menghapus transaksi

## Gunakan DOM untuk:

- Mengambil nilai dari form
- Menambahkan transaksi
- Menampilkan transaksi
- Memperbarui total

## ⚠️ Constraint

document.querySelector();
