# 04 — Expense Tracker Core

Setelah Level 3 selesai, tambahkan:

```js
getBalance();
getIncome();
getExpense();
```

Contoh:

```js
tracker.addIncome('Gaji', 5000000);
tracker.addExpense('Makan', 50000);
tracker.addExpense('Transport', 20000);
```

Maka:

```js
tracker.getIncome();
```

→ 5000000

```js
tracker.getExpense();
```

→ 70000

```js
tracker.getBalance();
```

→ 4930000
